# 🚀 Encurtador de URLs com Spring Boot

Um projeto Full Stack desenvolvido em Java para facilitar o compartilhamento de links longos, transformando-os em códigos curtos e fáceis de gerenciar.

## 🛠️ Tecnologias Utilizadas
* **Backend:** Java 21, Spring Boot 3.x
* **Persistência:** Spring Data JPA
* **Banco de Dados:** H2 Database (In-Memory)
* **Frontend:** Thymeleaf & Tailwind CSS
* **Algoritmo:** Conversão Base62 para geração de hashes

## 📋 Funcionalidades
- [x] Encurtamento de URLs persistido em banco de dados.
- [x] Redirecionamento automático (HTTP 302).
- [x] Interface web responsiva.

## 🚀 Como Rodar o Projeto
1. Clone o repositório: `git clone https://github.com/seu-usuario/url-shortener.git`
2. Certifique-se de ter o **JDK 21** instalado.
3. Execute via terminal: `./mvnw spring-boot:run` ou pela sua IDE.
4. Acesse: `http://localhost:8080`
